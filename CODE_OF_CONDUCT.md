# Código de conducta

Este proyecto adopta una versión resumida del Contributor Covenant 2.1.

## Nuestro compromiso

Queremos un entorno abierto, respetuoso y colaborativo para todas las personas,
sin importar experiencia, identidad o procedencia.

## Comportamiento esperado

- Ser respetuoso en comentarios, revisiones y discusiones.
- Aceptar críticas técnicas de forma constructiva.
- Priorizar hechos, claridad y colaboración.
- Ayudar a que las decisiones queden documentadas.

## Comportamiento inaceptable

- Acoso, insultos o lenguaje discriminatorio.
- Difusión intencionada de información privada.
- Trolling, amenazas o sabotaje.
- Conductas que conviertan una revisión técnica en un ataque personal.

## Aplicación

Las personas responsables del proyecto pueden moderar, pausar o rechazar
participación cuando sea necesario para proteger a la comunidad.

## Alcance

Este código se aplica en issues, pull requests, revisiones, chats vinculados al
proyecto y cualquier espacio público donde el proyecto tenga presencia.
