# Política de seguridad

La seguridad de `chess-coach` se gestiona con divulgación responsable.

## Cómo reportar

Si encuentras una vulnerabilidad, no la publiques en un issue abierto.

Reporta el problema por una de estas vías:

- Email: `pbeasboc@gmail.com`
- GitHub Security Advisory privado del repositorio

Incluye, si puedes:

- Qué parte del sistema afecta.
- Pasos mínimos para reproducirlo.
- Impacto esperado y real.
- Capturas, logs o pruebas de concepto.

## Alcance

Solo se aceptan reportes sobre la rama `main` y el MVP soportado públicamente.
No se garantiza soporte para bifurcaciones, experimentos locales ni cambios no
publicados.

## Qué esperar

Responderemos lo antes posible con confirmación de recepción, evaluación inicial
y siguientes pasos. Si el hallazgo requiere coordinación, pediremos tiempo para
validarlo antes de publicar cualquier detalle.
