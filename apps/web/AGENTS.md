# Reglas de la aplicación web

- Diseña primero para pantallas estrechas y prueba también escritorio.
- Mantén legalidad y evaluación fuera de componentes React.
- Modela explícitamente estados de carga, cancelación, error y motor no disponible.
- Todo control esencial debe funcionar con teclado y tener nombre accesible.
- Respeta `prefers-reduced-motion` y no uses color como único indicador.
- No añadas activos, personajes o textos que imiten la identidad de Chess.com.
- Después de cambios visuales, verifica al menos un viewport móvil y uno de escritorio.
